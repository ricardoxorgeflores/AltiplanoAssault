# Evidencia individual — Flores Vargas Ricardo Jorge

**Responsabilidad:** Construcción de la escena en Unity y organización del proyecto

## Descripción de lo realizado

Se creó el proyecto en Unity 6 (URP) y la estructura de carpetas. Con apoyo de IA (Claude) se escribió el script de editor `ConstructorPuebloAndino.cs`, que genera texturas, mallas y materiales propios y arma la escena del Nivel 1: calle empedrada, casas de adobe, iglesia colonial, montañas nevadas, wiphalas, faroles, el personaje Chullito, soldados, llaminga, drone, obstáculos e ítems, con luz de atardecer y cámara lateral 2.5D. Se preparó el repositorio Git y la documentación del equipo.
